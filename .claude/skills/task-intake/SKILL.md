# Task intake

1. Read everything: every attachment, every image. Transcribe voice notes before acting.
2. Search the backlog for the same subject. If it exists, extend it; never file it twice.
3. Write the entry: the requester's exact words and date, 3–5 testable acceptance criteria (one for mobile), and what is out of scope.
4. Task numbers come only from the Tech Lead. Without one, use a short kebab-case name.
5. Challenge it before coding: who needs it, what already exists, what is the smallest correct change. If unclear, ask the Tech Lead first.
